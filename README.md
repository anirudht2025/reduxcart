# 🛒 REDUXCART

A modern e-commerce application built with **React** and **Redux Toolkit**. REDUXCART allows users to browse products, search products, manage their cart, and maintain a wishlist.

## 🚀 Features

- 🛍️ Browse products
- 🔍 Search products
- 📄 Product pagination
- 👀 View individual product details
- 🛒 Add products to cart
- ➕ Increase/decrease cart quantity
- 🗑️ Remove products from cart
- 💳 Checkout and clear cart
- ❤️ Add products to wishlist
- ❌ Remove products from wishlist
- 🔄 Move wishlist products to cart
- 📊 Dynamic cart and wishlist counts
- ⏳ Loading and error states
- 💾 Product data stored in session storage

## 🛠️ Technologies Used

- React
- Redux Toolkit
- React Redux
- React Router
- React Bootstrap
- Bootstrap
- Axios
- React Icons
- DummyJSON API
